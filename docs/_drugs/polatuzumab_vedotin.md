# Polatuzumab Vedotin：從瀰漫性大B細胞淋巴瘤到 HER2 陽性乳癌

## 一句話摘要

Polatuzumab vedotin 是一款標靶 CD79b 的抗體藥物複合體（ADC），原本用於治療 CD79b 陽性之瀰漫性大B細胞淋巴瘤（DLBCL）。TxGNN 模型預測其可能對 **HER2 陽性乳癌** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有知識圖譜嵌入相似度分數作為依據。

## 這項預測合理嗎？

證據包中結構化的 `original_moa` 欄位標記為資料缺口（DG002，高嚴重度），但預測適應症的機轉敘述提供了已知資訊：Polatuzumab vedotin 是抗 CD79b 抗體藥物複合體，彈頭為微管抑制劑 MMAE，臨床上鎖定 B 細胞受體複合體上的 CD79b 抗原，用於 CD79b 陽性之瀰漫性大B細胞淋巴瘤。

HER2 陽性乳癌的致病機轉是 HER2/ERBB2 受體酪胺酸激酶訊號路徑過度活化，與 CD79b／B 細胞抗原生物學上**完全不重疊**。除非乳癌細胞異常表現 CD79b（極罕見且本證據包中無任何資料支持這種情況），否則沒有已知的生物學路徑可解釋此藥物對 HER2 陽性乳癌具有療效。

因此，本預測應被視為 TxGNN 知識圖譜嵌入相似性所產生的**純統計關聯**（分數 0.993），而非具有機轉支持的假說。這也是本案被評為 L5、決策階段 S0 的主要原因。

## 結論與後續步驟

**決策：Hold**

**理由：**
- 完全沒有臨床試驗或文獻支持（證據等級 L5，決策階段 S0）；
- 機轉分析顯示 CD79b 與 HER2 訊號路徑無生物學重疊，預測僅為模型嵌入相似度產生的統計關聯，缺乏合理機轉支持；
- 仿單警語／禁忌症資料為阻斷性缺口（DG001），無法進入安全性初評。

**要繼續推進，需要補齊：**
- TFDA／加拿大仿單警語與禁忌症資料（DG001，阻斷性，需下載仿單 PDF 解析）
- 完整、結構化的作用機轉（MOA）資料以確認/推翻機轉假說（DG002）
- 若存在，補充乳癌細胞異常表現 CD79b 的相關臨床前或病例證據
- 若持續找不到生物學合理路徑，建議終止此候選方向而非投入進一步資源
