## Why is This Prediction Reasonable?

Detailed mechanism-of-action data are not available in the compiled data. Bendamustine is generally described as an alkylating agent with purine-analog-like properties: it cross-links DNA and triggers apoptosis in B-cell malignancies.

Mantle cell lymphoma is a mature B-cell neoplasm, biologically close to the B-cell lymphomas in which bendamustine is already used, so the cytotoxic mechanism plausibly applies directly. Bendamustine plus rituximab is already an established backbone regimen in mantle cell lymphoma, and it serves as the comparator or backbone in several large Phase 3 trials.

## Safety Considerations

- **Conditions flagged as contraindications in the compiled data:** liver failure, kidney disease, liver disease, gallbladder disease, pyoureter, thrombocytopenia, neutropenia, agranulocytosis, anaemia and macrocytic anaemia. These are not label text and should be checked against the package insert.
- **Drug Interactions:** 100 interactions were recorded. Major-level interactions include deferiprone and samarium (153Sm) lexidronam, both of which carry added bone-marrow suppression concerns. Moderate-level examples include omeprazole, esomeprazole, cimetidine, caffeine, mercaptopurine and ticlopidine.

Please refer to the package insert for complete safety information.
