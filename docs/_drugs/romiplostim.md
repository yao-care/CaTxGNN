# Romiplostim: From Thrombopoietin-Receptor Agonist Use to Primary Release Disorder of Platelets

## One-Sentence Summary

Romiplostim is a thrombopoietin (TPO) receptor agonist that raises platelet counts, and it is marketed in Canada as NPLATE. The TxGNN model predicts it may be effective for **primary release disorder of platelets**, but only **1 observational clinical trial** and **2 publications** (a review and a laboratory study) touch on this indication, and none tests romiplostim for it. This prediction is best treated as a hypothesis, not an evidence-backed opportunity.

## Why is This Prediction Reasonable?

Detailed mechanism-of-action data is not available in the supplied record. Based on its drug class, romiplostim is a TPO-receptor agonist that stimulates platelet production, so it raises platelet *count*.

A platelet release (secretion) disorder is different. It is a defect in platelet *function*: platelets are present in normal numbers but do not release their granule contents properly. Raising the count would not be expected to correct this. The high graph score most likely reflects shared biology with immune thrombocytopenia (ITP), a disease where romiplostim is well studied, and not a functional rationale. The prediction is therefore mechanistically weak.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The predicted indication is a platelet function defect, while romiplostim increases platelet count. The only supporting evidence is one observational ITP study and two background papers, none of which tests romiplostim in this condition.

For context, among the other predictions in this pack, "platelet-type bleeding disorder" (rank 8) carries L1 evidence, including the completed Phase 3 RECITE trial (NCT03362177). That evidence concerns thrombocytopenia, not platelet function disorders, and the label is a broad umbrella that would need to be scoped before any decision.

**To proceed, the following is needed:**
- Mechanism-of-action data for romiplostim, to test whether any link to platelet release function exists
- Health Canada package insert warnings and contraindications, which block safety screening
- Approved indication text for the two Canadian licences
- Any direct preclinical or clinical data on romiplostim in platelet release disorders
