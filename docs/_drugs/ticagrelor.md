# Ticagrelor: From Antiplatelet Therapy (Acute Coronary Syndrome) to Intracranial Arteriosclerosis

## One-Sentence Summary

Ticagrelor is a P2Y12 receptor inhibitor established as core antiplatelet therapy for ischemic cardiovascular disease (acute coronary syndrome / percutaneous coronary intervention).
The TxGNN model predicts it may also be effective for **Intracranial Arteriosclerosis** (intracranial atherosclerotic disease, ICAD),
with **11 clinical trials** and **3 publications** currently supporting this direction — though the pivotal disease-specific Phase 3 trial has not yet reported results.

## Why is This Prediction Reasonable?

Currently, detailed mechanism of action data is not available for this drug record (data gap DG002). Based on information present elsewhere in this evidence pack, ticagrelor is a reversible, direct-acting **P2Y12 receptor antagonist** that blocks ADP-induced platelet activation, and is a core agent for ischemic cardiovascular disease — acute coronary syndrome, post-PCI dual antiplatelet therapy, and secondary stroke prevention.

Intracranial arteriosclerosis (ICAD) is mechanistically a direct extension of the same atherothrombotic pathology: progressive atherosclerotic narrowing of intracranial arteries leads to recurrent ischemic stroke, and the current standard of care for symptomatic ICAD is dual antiplatelet therapy (typically clopidogrel + aspirin). Ticagrelor's P2Y12-inhibiting mechanism is directly applicable as an alternative or adjunct antiplatelet strategy in this population — this is particularly relevant for patients who are poor responders to clopidogrel due to CYP2C19 loss-of-function variants, a population specifically targeted in one of the ongoing trials below (NCT06714526).

Importantly, the disease-specific pivotal evidence is still maturing: the Phase 3 **CAPTIVA** trial (NCT05047172), which directly compares ticagrelor, rivaroxaban, and clopidogrel arms for intracranial vascular atherostenosis, is active but not yet complete (estimated completion 2028-05-31). This places the candidate at evidence level L2 — mechanistically well-supported and undergoing dedicated Phase 3 investigation, but without a completed, disease-specific RCT readout yet.

## Conclusion and Next Steps

**Decision: Hold (Research Question stage)**

**Rationale:**
Evidence for intracranial arteriosclerosis sits at L2 with decision stage S2 ("Research Question") — the mechanistic rationale is strong and a dedicated Phase 3 trial (CAPTIVA, NCT05047172) is actively underway, but no completed disease-specific RCT has yet reported results. This is compounded by a **Blocking** data gap (TFDA-equivalent warnings/contraindications, DG001) that prevents safety pre-assessment, and the fact that ticagrelor is not currently marketed in Canada (0 DINs), meaning no local regulatory pathway is presently established.

**To proceed, the following is needed:**
- Primary results from the CAPTIVA trial (NCT05047172, estimated completion 2028-05-31)
- TFDA-equivalent package insert warnings/contraindications (DG001 — Blocking)
- Original mechanism-of-action documentation (DG002)
- Drug interaction (DDI) data — current query status is "not found"
- Assessment of a Canadian regulatory/market entry pathway (currently 0 DINs)
